# SATI 动物抽卡收集

基于新版 `SATI测试题库与匹配机制(1).xlsx` 重构的静态 Web 原型：用户完成 8 道场景题后，系统按题库中的动物映射计分，揭晓最像的灵魂动物卡，并把已获得的动物卡保存到本地图鉴中。

## 当前 MVP

- 首页进入 8 题 SATI 测试，题干、选项和动物映射来自新版 Excel。
- 每个选项对应 1 个动物，答完后按动物得分排序。
- 单动物最高分解锁 1 张卡。
- 双动物并列第一展示「混合灵魂」双卡，并同时解锁 2 张卡。
- 3 个及以上并列第一时，根据答题路径稳定抽取 2 张混合卡，保证结果有变化且可复测。
- 图鉴收藏使用 `localStorage["satiUnlockedAnimals"]` 持久保存。
- 「再测一次」只重置本轮答题，不清空图鉴收藏。
- 深度解析 Part1 直接展示；Part2 使用按钮解锁，保留广告位机制感但不接真实广告 SDK。

## 数据文件

- `sati-data.js`：由新版 Excel 题库整理出的 8 道题、12 个动物结果和解析内容。
- `app.js`：SATI 测试、计分、并列处理、图鉴收藏和页面切换逻辑。
- `styles.css`：动物卡、混合灵魂、图鉴网格、揭晓动效和移动端适配。

## 验证路径

- 狐狸单结果：`D, D, C, C, B, A, B, D`
- 猫 + 猫头鹰双并列：`A, A, A, A, C, D, B, C`
- 多动物并列稳定双卡：`A, A, A, A, A, D, B, A`
