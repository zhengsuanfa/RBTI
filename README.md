# 今天别做自己 / RBTI 挑战

用户先选择自己的 MBTI 人格底色，再用 8 题极速测评判断“今天最像哪种人”。系统会根据“人格底色 + 今日卡点”生成一个 3 分钟反着来挑战，并输出一张 SBTI 式的 RBTI 今日结果卡。

这是为抖音 AI 创变者计划黑客松准备的「赛道一 互动空间」Web 原型。它把 MBTI 从静态标签变成可玩的互动挑战：用户不只是知道自己是谁，而是在三关里练一次反着来的小动作。

## 当前 MVP

- 支持 8 题极速 RBTI 测评，覆盖不说需求、一直想想、不好拒绝、总想自己来、灵感跑偏、一开口就反驳、先冲再说、低电量硬撑
- 测评完成后自动给出今日 RBTI 倾向，例如 `ASK 都可以本人`、`NO 说不出口人`、`NEW 新想法插队人`
- 支持 16 型 MBTI 作为人格底色输入
- 8 题结果自动决定今日状态、挑战强度和挑战模板
- 自动生成挑战名、今日 Boss、目标和三关选择
- 每关只保留 A/B/C 三个直观选择
- 实时更新 Boss 血量、勇气值、逃避值和完成度
- 通关后生成 RBTI 结果卡，例如 `ASK 都可以本人`、`CTRL 还是我来吧人`、`MVP 再想五分钟人`
- 结果同时展示测评依据和闯关选择路径，适合截图分享和好友互相投喂

## 路演表达

现在很多人格产品都停留在“测你是谁”。最近 SBTI 能刷屏，是因为它的结果够直观、够像嘴替、够适合截图。《今天别做自己》把这个传播机制接到互动空间里：用户先选择一个人格底色，再用 8 个高频行为场景判断今天最像哪种人，进入对应的反着来挑战，最后得到自己的 RBTI 今日结果卡。

比如用户选择 INFP 作为人格底色，8 题测出“不说需求”，系统生成“便利店开口试炼”；用户选择 ENTJ，8 题测出“总想自己来”，系统生成“控制狂休假日”。用户在三关里做选择，最后获得一张可分享的结果卡：`BOSS Boss 扣血狂魔`、`NO 说不出口人`、`SIDE 绕路开门人` 等。
