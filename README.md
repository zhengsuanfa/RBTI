# 今天别做自己 / 反人格副本

用户先选择自己的 MBTI 人格底色，再用 8 题极速测评定位今天最明显的行为惯性。系统会根据“人格底色 + 今日卡点”生成一个“最不顺手但安全可玩”的 3 分钟反人格副本，并输出一张 SBTI 式的 RBTI 今日抽象人格结果。

这是为抖音 AI 创变者计划黑客松准备的「赛道一 互动空间」Web 原型。它把 MBTI 从静态标签变成可玩的互动挑战：用户不只是知道自己是谁，而是在三关里练一次反着来的小动作。

## 当前 MVP

- 支持 8 题极速 RBTI 测评，覆盖需求表达、行动启动、边界拒绝、控制协作、注意力收束、冲突回应、冲动刹车、能量管理
- 测评完成后自动给出“最高惯性”和今日 RBTI 倾向，例如 `ASKR 小声开口侠`、`NOPE 边界修复师`、`FOCS 单线程续命人`
- 支持 16 型 MBTI 作为人格底色输入
- 8 题结果自动决定今日状态、挑战强度和副本模板
- 自动生成副本名、今日 Boss、通关目标和三关挑战
- 每关提供人格惯性、低压绕路、反向动作三种选择
- 实时更新 Boss 血量、勇气值、逃避值和完成度
- 通关后生成 RBTI 结果卡，例如 `ASKR 小声开口侠`、`CTRL 控制权松手人`、`MVP 先交一版人`
- 结果同时展示测评依据和闯关选择路径，适合截图分享和好友互相投喂

## 路演表达

现在很多人格产品都停留在“测你是谁”。最近 SBTI 能刷屏，是因为它的结果够抽象、够像嘴替、够适合截图。《今天别做自己》把这个传播机制接到互动空间里：用户先选择一个人格底色，再用 8 个高频行为场景抓出今日惯性，进入对应的反人格副本，最后得到自己的 RBTI 今日抽象人格。

比如用户选择 INFP 作为人格底色，8 题测出“需求表达”卡点，系统生成“便利店开口试炼”；用户选择 ENTJ，8 题测出“控制协作”卡点，系统生成“控制狂休假日”。用户在三关里做选择，最后获得一张可分享的结果卡：`BOSS Boss 扣血狂魔`、`NOPE 边界修复师`、`SIDE 绕路式勇敢人` 等。
